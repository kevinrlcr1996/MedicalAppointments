# Security

Implemented in Phase 1:

- JWT bearer.
- Development-only token endpoint.
- Authorization policies.
- Granular permission claims.
- Rate limiting.
- CORS.
- Security headers.
- ProblemDetails without stack traces.
- CorrelationId.
- No secrets in Git.

Planned:

- ASP.NET Core Identity or equivalent.
- Refresh token rotation.
- Password hashing.
- Account lockout.
- Resource-based authorization.
- Medical records least privilege.
