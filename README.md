# Medical Appointments Platform

Plataforma profesional para gestión y reserva de citas médicas.

## Stack

### Backend

- .NET 10
- ASP.NET Core Web API
- Entity Framework Core 10
- SQL Server
- JWT
- FluentValidation
- Serilog
- SignalR
- Outbox Pattern
- BackgroundService

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- React Hook Form
- Zod
- @microsoft/signalr

## Restricciones

- No usar MediatR.
- No usar JavaScript en frontend.
- No usar CSS de componentes.
- Tailwind obligatorio.
- REST es la API principal.
- SQL Server es la fuente de verdad.
- SignalR no es la fuente de verdad.
- Ningún servicio pago obligatorio.
