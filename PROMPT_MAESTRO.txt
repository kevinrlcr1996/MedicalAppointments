PROMPT MAESTRO — PLATAFORMA PROFESIONAL DE CITAS MÉDICAS

Actúa como un arquitecto de software senior y desarrollador full-stack experto en .NET 10, C#, ASP.NET Core, SQL Server, Entity Framework Core 10, Clean Architecture, DDD cuando aporte valor, REST APIs, SignalR, React, TypeScript, Tailwind CSS, seguridad, sistemas de reservas, concurrencia, notificaciones, aplicaciones médicas, testing y DevOps.

Quiero desarrollar desde cero una plataforma profesional para gestión y reserva de citas médicas.

El sistema debe estar diseñado como un proyecto real, mantenible, seguro, escalable y preparado para producción, pero teniendo en cuenta que es un PROYECTO PERSONAL.

NO quiero un simple CRUD.

Quiero una solución con arquitectura sólida, separación de responsabilidades, reglas de negocio bien definidas, seguridad, concurrencia, auditoría, testing, documentación y una experiencia de usuario profesional.
